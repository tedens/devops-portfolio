I'm a DevOps Manager, professional since 2012. The last eight years or so have
been automation-first infrastructure; full-stack development and Linux systems
work have run alongside that the whole time rather than stopping when the DevOps
started. I first wrote code at thirteen, which is a nicer story than it is a
qualification.

The overlap is the useful part: I've been the person paged at 3am, and I've been
the person whose code caused it.

## Now

I lead the DevOps function at a healthcare SaaS, where I:

- Architect and run multi-account Kubernetes infrastructure at **>99.995% uptime**
- Operate secure, audit-ready CI/CD for web and mobile
- Drive cost work that has removed **over 60%** of cloud spend
- Mentor engineers on observability, reliability and DevSecOps
- Oversee internal IT operations and support HIPAA and SOC 2 compliance

## Before

At AC Moore and Capstan I supported AI/ML infrastructure through M&A
transitions, the kind of work where two of everything exists and neither can
go down. Earlier I built and supported high-availability systems for hosting
providers including SingleHop and InMotion Hosting, which is where I learned
what actually breaks at scale.
